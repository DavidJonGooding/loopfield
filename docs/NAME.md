# Name decision

“Loopr” is short and immediately communicates looping, but an established app in the same category already uses it: [Loopr Live Loop Composer](https://apps.apple.com/us/app/loopr-live-loop-composer/id544645268). Other software also uses the name. This creates avoidable discovery/confusion problems for a new public project.

The owner selected **Loopfield** after comparing it with Phraseweave. Loopfield is pronounceable, suggests a space for building musical layers, and fits the existing minimal waveform identity. The initial web search did not reveal an obvious music-app collision. This is preliminary naming research, not a trademark clearance or a guarantee of name availability.

Use `DavidJonGooding/loopfield` as the repository, Loopfield as the public product name, and `.loopfield` for new sessions while accepting `.loopr` imports.
