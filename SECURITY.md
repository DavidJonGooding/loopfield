# Security

Loopfield processes audio locally. The web app uses local browser storage and explicit exports; the support link opens Buy Me a Coffee separately. No audio upload service or application telemetry is included.

For a sensitive security issue, use GitHub's private vulnerability reporting for this repository when enabled. Do not attach credentials or private recordings to public issues. General bugs can be reported publicly with reproduction steps and device/browser versions.

Desktop packages should be checked against the release checksum. Experimental Mac packages are ad-hoc signed and are not notarized until the maintainer configures Apple signing. Do not treat an Actions build as a hardware compatibility certification.
